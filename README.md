# Git Assignment – Overview

This repository contains a complete set of Git and GitHub operations practiced as part of the assignment.

## Topics Covered

- Initializing a local Git repository and basic staging/unstaging
- Connecting to a remote repository and pushing/pulling changes
- Creating branches, making commits, and raising/merging Pull Requests
- Local branch creation (`b1`, `b2`, `b3`), interactive staging (`git add -p`), soft & hard resets
- Merging branches and resolving merge conflicts
- Forking the repository, making changes in the fork, and creating a Pull Request from the fork to the original repository
- Advanced operations: selective staging, stash, `git rm`, and `git revert`
